# `.agents` — скіли локального агента (робочий простір)

Ця папка — **головний набір скілів для агента в репозиторії Talan UA Antigravity manager**.

Тут дозволено (і очікувано):

- згадки **ГО «Талан ЮА»**, внутрішніх проєктів (Ашрам, Новий Шлях тощо);
- локальні шляхи (`Knowledge_Base/`, `_DROPZONE/`, установчі документи);
- скіли-розширення: `02-manager-talan`, `context_*.md`, `Talan_Grant_Methodology.md`.

## Не плутати з продуктом

| | **`.agents/` (тут)** | **`Universal-AI-Orchestrator/.agents/`** |
| :--- | :--- | :--- |
| **Призначення** | Агент власника репо | Скіли для **продажу** покупцю |
| **Контекст** | ГО, ваші проєкти, внутрішні дані | Універсальний, знеособлений |
| **Правило** | Повний локальний контекст | **DE-NGO-ified** — жодних імен ГО/проєктів клієнта |

Протокол «Двох розумів»: `.agents/skills/01-orchestrator/SKILL.md` §1.8.

## Дзеркальна синхронізація (Mirror Law)

Якщо покращення скілу **універсальне** (методологія, пайплайн, compliance):

1. Спочатку — у **продукті** (`Universal-AI-Orchestrator/.agents/skills/`), без приватного контексту.
2. Потім — у **локальному** скілі з `references/` або `context_*.md` для специфіки ГО.

Локальні доповнення **не копіюються** в продукт.
