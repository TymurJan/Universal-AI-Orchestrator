# Регламент: Запуск та зупинка Telegram-бота

## Опис
Цей workflow містить інструкції щодо правильного (тихого або консольного) запуску та зупинки Telegram-бота ГО "Талан ЮА".

## Кроки для ручного запуску (з консоллю)
1. Відкрийте корінь проєкту `Talan UA Antigravity manager`.
2. Запустіть файл:

```powershell
.\_start_bot.bat
```
*Цей скрипт автоматично активує віртуальне середовище (.venv) та запустить `bot.py` із відображенням логів у консолі.*

## Кроки для тихого запуску (у фоні, без консолі)
Для того, щоб бот працював непомітно і не заважав вікном терміналу:

```powershell
.\talan.autobot\run_bot_silent.vbs
```

## Кроки для зупинки бота
Якщо бот запущений у фоні (через `vbs` або як сервіс), скористайтеся цим скриптом для його безпечного завершення (він "вб'є" процес python.exe, пов'язаний з ботом):

```powershell
.\talan.autobot\stop_bot.bat
```

## Автозапуск через Windows Task Scheduler
Для реєстрації бота як фонової служби, що стартує разом з Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\talan.autobot\create_task.ps1
```
*(Для видалення задачі з автозавантаження використовуйте `remove_task.ps1`)*
