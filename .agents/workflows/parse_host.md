# 🚀 Воркфлоу: "Парси Хост"

Цей воркфлоу активовується фразою "парси хост". Він гарантує, що жодна крапка не загубиться, а жоден секрет не витече.

## 🛡️ ЗАХИСТ СЕКРЕТІВ (.env)

Файл `.env` — це серце безпеки. Після "парсингу" (деплою) відбувається наступне:

1.  **Ізоляція образа:** Секрети **НІКОЛИ** не потрапляють всередину Docker-образа. Вони залишаються на сервері-хості.
2.  **Runtime Injection:** Docker Compose зчитує `.env` лише в момент запуску і передає змінні в пам'ять процесу. На диску всередині контейнера файлу `.env` не існує.
3.  **Lockdown:** Після деплою ми виконуємо `chmod 600 .env` (на Linux), що робить файл доступним ТІЛЬКИ для власника (root/deployer).

## 🪜 КРОКИ ДЕПЛОЮ (Парсинг)

### 1. Транспорт (Secure Sync)
Всі 18,165 файлів (включаючи `Universal-AI-Orchestrator`) синхронізуються через захищений тунель (SCP/SFTP/Rsync).

### 2. Створення середовища
На сервері створюється структура:
- `/opt/talan-manager/` — корінь екосистеми.
- `/opt/talan-manager/.env` — створюється вручну або копіюється через захищений канал.

### 3. Запуск Екосистеми
```bash
docker compose up -d --build
```

### 4. Активація Talan Shield (Double Front Door)
- **Двері 1 (Cloudflare):** Налаштування DNS на проксіювання (Proxy ON). Це приховує справжній IP сервера.
- **Двері 2 (Internal):** ThrottlingMiddleware у кожному боті відсікає атаки, що пройшли крізь фільтри.
