# Пошук Скілів (Find Skills)

Цей скіл допомагає знаходити та встановлювати скіли з відкритої екосистеми навичок для агентів.

## Коли використовувати цей скіл

Використовуйте цей скіл, коли користувач:

- Запитує "як мені зробити X", де X може бути типовим завданням, для якого вже існує скіл
- Каже "знайди скіл для X" або "чи є скіл для X"
- Запитує "чи можеш ти зробити X", де X є спеціалізованою можливістю
- Виявляє інтерес до розширення можливостей агента
- Хоче знайти інструменти, шаблони чи робочі процеси (workflows)
- Згадує, що йому потрібна допомога в певній галузі (дизайн, тестування, розгортання тощо)

## Що таке Skills CLI?

Skills CLI (`npx skills`) — це менеджер пакетів для відкритої екосистеми скілів для агентів. Скіли (навички) — це модульні пакети, які розширюють можливості агента спеціалізованими знаннями, процесами та інструментами.

**Основні команди:**

- `npx skills find [запит]` - Пошук скілів інтерактивно або за ключовим словом
- `npx skills add <package>` - Встановлення скіла з GitHub або інших джерел
- `npx skills check` - Перевірка оновлень для скілів
- `npx skills update` - Оновлення всіх встановлених скілів

**Переглядайте скіли на:** https://skills.sh/

## Як допомогти користувачам знайти скіл

### Крок 1: Зрозумійте, що їм потрібно

Коли користувач просить про допомогу з чимось, визначте:

1. Доменну область (наприклад, React, тестування, дизайн, розгортання)
2. Конкретне завдання (наприклад, написання тестів, створення анімацій, рев'ю PR)
3. Чи є це достатньо типовим завданням, для якого ймовірно вже існує скіл

### Крок 2: Пошук скілів

Запустіть команду `find` з відповідним запитом:

```bash
npx skills find [запит]
```

Наприклад:

- Користувач запитує "як зробити мій React додаток швидшим?" → `npx skills find react performance`
- Користувач запитує "чи можеш допомогти з PR рев'ю?" → `npx skills find pr review`
- Користувач каже "мені потрібно створити changelog" → `npx skills find changelog`

Команда поверне результати на зразок:

```
Install with npx skills add <owner/repo@skill>

vercel-labs/agent-skills@vercel-react-best-practices
└ https://skills.sh/vercel-labs/agent-skills/vercel-react-best-practices
```

### Крок 3: Запропонуйте варіанти користувачу

Коли знаходите релевантні скіли, покажіть їх користувачу разом з:

1. Назвою скіла та інформацією про те, що він робить
2. Командою для його встановлення
3. Посиланням на skills.sh для детальнішого ознайомлення

Приклад відповіді:

```
Я знайшов скіл, який може допомогти! Скіл "vercel-react-best-practices" 
надає рекомендації щодо оптимізації продуктивності React та Next.js від команди Vercel.

Для його встановлення виконайте:
npx skills add vercel-labs/agent-skills@vercel-react-best-practices

Дізнайтеся більше: https://skills.sh/vercel-labs/agent-skills/vercel-react-best-practices
```

### Крок 4: Запропонуйте встановити

Якщо користувач хоче продовжити, ви можете встановити для нього скіл:

```bash
npx skills add <owner/repo@skill> -g -y
```

Прапорець `-g` встановлює глобально (на рівні користувача), а `-y` пропускає підтвердження.

## Популярні категорії скілів

Під час пошуку орієнтуйтеся на ці популярні категорії:

| Категорія | Приклади запитів |
| --- | --- |
| Веб-розробка | react, nextjs, typescript, css, tailwind |
| Тестування | testing, jest, playwright, e2e |
| DevOps | deploy, docker, kubernetes, ci-cd |
| Документація | docs, readme, changelog, api-docs |
| Якість коду | review, lint, refactor, best-practices |
| Дизайн | ui, ux, design-system, accessibility |
| Продуктивність | workflow, automation, git |

## Поради для ефективного пошуку

1. **Використовуйте конкретні ключові слова**: "react testing" краще, ніж просто "testing"
2. **Пробуйте альтернативні терміни**: Якщо "deploy" не працює, спробуйте "deployment" або "ci-cd"
3. **Перевіряйте популярні джерела**: Багато скілів можна знайти у `vercel-labs/agent-skills` або `ComposioHQ/awesome-claude-skills`

## Що робити, якщо скілів не знайдено

Якщо релевантних скілів не знайдено:

1. Повідомте користувача, що існуючих скілів не знайдено
2. Запропонуйте допомогти із завданням напряму, використовуючи ваші загальні можливості
3. Порадьте користувачу створити власний скіл за допомогою команди `npx skills init`

Приклад:

```
Я пошукав скіли, пов'язані з "xyz", але нічого не знайшов.
Я все одно можу допомогти вам із цим завданням напряму! Хочете продовжити?

Якщо це завдання, яке ви робите часто, ви можете створити власний скіл:
npx skills init my-xyz-skill
```
