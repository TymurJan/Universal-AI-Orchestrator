# 📊 Market Analyzer (Стратегічний Аналітик)

Цей скіл дозволяє вам (Агенту) автоматично розраховувати потенціал ринку за методологією **TAM, SAM, SOM** перед тим, як рекомендувати бізнес-рішення клієнту (або розпочинати моніторинг через `web-scout`).

## Що вміє інструмент

Він бере вхідні дані про ринок та математично розраховує воронку:
- **TAM** (Total Addressable Market) — весь обсяг ринку.
- **SAM** (Serviceable Available Market) — частка, до якої технічно і логістично можна дотягнутись.
- **SOM** (Serviceable Obtainable Market) — реальна мета для відділу продажів / стартапу.

Результат зберігається як `.md` звіти та `.json` файли для подальшого аудиту. Інструмент фізично існує як CLI скрипт.

## Як викликати інструмент (CLI)

Коли клієнт просить "оціни ринок", "порахуй TAM", "який потенціал індустрії", викликай скрипт оркестратора через термінал.

```bash
# Базовий розрахунок
python tools/market_analyzer_tool.py analyze \
  --industry "SaaS для ресторанів" \
  --region "Україна" \
  --total_clients 50000 \
  --avg_check 600 \
  --sam_percent 15 \
  --som_percent 5

# Подивитися попередні звіти
python tools/market_analyzer_tool.py list
```

## Правила поведінки Агента з цим скілом

1. **Завжди уточнюй дані**: Якщо користувач каже "оціни ринок кав'ярень", ти спочатку маєш знайти або передбачити `total_clients` (кількість кав'ярень) та `avg_check` (розмір середнього чеку за софт або каву). 
2. **Не вигадуй результати**: Ти ПОВИНЕН викликати `market_analyzer_tool.py` і надати користувачеві вивід із скрипта. Продукт має працювати не на словах, а у вигляді реальних згенерованих файлів звітів.
3. **Зв'язка з Web Scout**: Після того, як звіт згенеровано, запитай клієнта: *"Чи хочете ви, щоб я передав топ-гравців цього ринку на постійний моніторинг моєму модулю Web-Scout?"*
