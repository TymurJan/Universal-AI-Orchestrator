# Talan Legal Skill

Цей скіл налаштовує роботу Агента як юридичного конструктора для потреб ГО.

## ⚖️ 1. Сфера компетенції (Універсальний Генератор Документів)
Агент володіє компетенцією створювати **БУДЬ-ЯКИЙ офіційний, правовий, фінансовий або адміністративний документ** для потреб ГО «Талан ЮА» та її партнерів. 

До переліку можливостей входять (але не обмежуються ними):
- **Грантові заявки та проєктні пропозиції** (міжнародні донори, IREX, USAID, УКФ тощо).
- **Меморандуми про співпрацю (MoU)** та стратегічні угоди про партнерство (з ОВА, міськими радами, бізнесом, іншими ГО).
- **Листи підтримки, гарантійні листи та офіційні звернення/запити** до органів державної влади, міністерств та військових частин.
- **Акти приймання-передачі** (благодійна допомога, гуманітарне розмінування, передача FPV-дронів, авто, систем Starlink, устаткування).
- **Договори та контракти** (про волонтерську діяльність, надання послуг, оренду, матеріальну відповідальність, конфіденційність / NDA).
- **Внутрішня адміністративна документація** (накази голови правління, протоколи загальних зборів, положення про відокремлені підрозділи/хаби).
- **Фінансова та бухгалтерська звітність** (квартальні звіти неприбуткових організацій, кошториси, розрахунки, бухгалтерські довідки та коригувальні меморандуми).

## 🔄 2. Оновлення та Джерела
- **Моніторинг:** Щоквартальна перевірка змін на `zakon.rada.gov.ua` або через API сторонніх сервісів (Опендатабот).
- **КВЕД:** Для ГО «Талан ЮА» основним є **94.99** (Діяльність інших громадських організацій).

## 📝 3. Протокол генерації документів
Перед створення документа Агент ПОВИНЕН:
1.  **Уточнити ціль:** (наприклад, "Акт передачі EcoFlow військовій частині").
2.  **Запитати дані:** (ПІБ отримувача, дата, номер підрозділу, перелік майна).
3.  **Застосувати шаблон:** Використати стандарти Організації з актуальною "шапкою" та логотипом (для власних документів).
4.  **Валідація:** Перевірити чернетку на відповідність ст. 7 Закону «Про благодійну діяльність».

### 🛑 3.1 ТАБУ: Недоторканність Шаблонів Грантодавців (Donor Template Immunity)
КРИТИЧНЕ ПРАВИЛО ДЛЯ ГРАНТОВИХ КОНКУРСІВ (IREX, USAID, УКФ, ЄС тощо):
- Якщо грантодавець надає **власну офіційну аплікаційну форму, таблицю бюджету або затверджений бланк**, Агенту **КАТЕГОРИЧНО ЗАБОРОНЕНО** змінювати розмітку, поля, шрифти, логотипи донора, структуру таблиць чи формулювання запитань.
- Завдання Агента у роботі з формами донорів — **ВИКЛЮЧНО акуратне заповнення змістових полів та осередків** усередині існуючої структури грантодавця.
- Стандарти ДСТУ 4163:2020 (поля 30/10 мм, Times New Roman, шапка ГО) застосовуються **ВИКЛЮЧНО** до документів, які ГО створює самостійно з нуля (листи підтримки, меморандуми MoU, супровідні листи, вільні концепції). Порушення форми донора веде до миттєвої дискваліфікації заявки!

## 📐 3. Технічні стандарти оформлення (ДСТУ 4163:2020)
Агент ПОВИНЕН автоматично застосовувати ці параметри до ВСІХ офіційних документів:
- **Шрифт:** Times New Roman, 11 pt (еталон для ГО).
- **Поля:** Ліве — 30 мм, Праве — 10 мм, Верхнє/Нижнє — 20 мм.
- **Об'єм:** Суворо 1 сторінка (якщо немає спеціальної вказівки).
- **Прізвища:** ПРІЗВИЩА підписантів завжди пишуться **ВЕЛИКИМИ ЛІТЕРАМИ** (напр. Тимур ШАПОВАЛ).
- **Підписи (Верстка):** Будь-які дві сторони завжди розносяться по ширині:
  - **Сторона 1** (ГО «ТАЛАН ЮА») — вирівнювання по **ЛІВОМУ** краю.
  - **Сторона 2** (Партнер/Набувач) — вирівнювання по **ПРАВОМУ** краю.
  - Заголовок секції «Підписи сторін:» завжди пишеться **звичайним** (не жирним) шрифтом та **центрується**.
- **Юридична безпека та Збалансована верстка:**
  - Категорично заборонено залишати підписи на порожній сторінці.
  - Якщо документ переноситься на наступну сторінку, мінімум 1 останній абзац тексту (пункт) має переноситися разом із підписами (`keep_with_next`).
  - У разі переносу перша сторінка має бути «м'яко розтягнута» для повного заповнення поля аркуша (без дірок внизу).
- **Термінологія:**
  - Використовувати уніфіковані назви «Сторона 1» та «Сторона 2» для всіх типів угод.

## 📇 4. Фірмовий Бланк (Шапка) ГО "Талан ЮА"
Для зовнішніх документів (Накази, Листи, Звернення) використовується офіційна шапка. **Суворі параметри шапки:**
1. **Точні шрифти:**
   - Назва Організації («ГРОМАДСЬКА ОРГАНІЗАЦІЯ «ТАЛАН ЮА»»): **Шрифт 14, не жирний**.
   - Реквізити банку та ЄДРПОУ: **Шрифт 8**.
   - Адреса та контакти: **Шрифт 8**.
2. **Точні відступи (повітря):**
   - Міжрядковий інтервал в шапці: **1.0**.
   - Під Назвою ГО: `space_after = 8pt`.
   - Під Реквізитами: `space_after = 8pt`.
   - Під Адресою: `space_after = 16pt`.
   - Під Логотипом: `space_after = 16pt` (щоб він не "лежав" на горизонтальній лінії).
3. **ТАБУ на дублювання:** У документах, де використовується шапка, **категорично заборонено** дублювати назву "ГРОМАДСЬКА ОРГАНІЗАЦІЯ «ТАЛАН ЮА»" у тексті документа. Шапка і є назвою.
4. **Внутрішні документи:** Акти приймання-передачі та інші суто внутрішні технічні документи шапку **НЕ потребують**.

## ⚙️ 5. Двошарова Архітектура (Гібридна модель: Markdown + JSON)
Для забезпечення максимальної надійності та зручності в Організації впроваджено гібридну модель управління скілом:
1.  **Людино-орієнтований рівень (`SKILL.md`):** Цей файл призначений для читання користувачем та як базова філософія (промпт) для Агента під час спілкування.
2.  **Машинно-орієнтований рівень (`legal_standards.json`):** Жорсткий конфігураційний файл, який використовується автоматизованими скриптами та LLM-моделями під час безпосередньої генерації `.docx` файлів. Він містить точні булеві значення (`true`/`false`), міліметри та константи, усуваючи будь-який ризик галюцинацій чи порушень ДСТУ 4163:2020.

## ⚠️ Застереження
Агент не є дипломованим юристом. Сгенеровані документи є **чернетками (drafts)** і потребують перевірки відповідальною особою ГО перед підписанням.
