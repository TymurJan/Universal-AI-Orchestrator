# Чекліст Валідації (Skill Verification)

Запустіть ці перевірки перед тим, як запропонувати користувачеві використовувати новий скіл.

## 1. Структурна валідація
- [ ] Кількість рядків у `SKILL.md` менше 500?
- [ ] Назва папки співпадає з полем `name` у фронтматтері?
- [ ] Всі шляхи до файлів використовують прямий слеш `/`?

## 2. Логічна валідація
- [ ] Чи зрозумілий "Trigger" (умова активації) для AI?
- [ ] Чи немає в інструкціях логічних петель (коли А посилається на Б, а Б на А)?
- [ ] Чи додано чекліст прогресу (для Workflow-патернів)?

## 3. Безпека
- [ ] Чи не містить скіл конфіденційної інформації (паролі, ключі, PII)?
- [ ] (Опціонально) Чи перевірено сумісність з `talanregulations`, якщо скіл створюється для цього проекту?

## 4. Smoke-test
- [ ] "Прочитай SKILL.md нового скіла. Чи розумієш ти свою нову роль?"
- [ ] Виконання одного навчального прикладу.
