# Corporate Legal Architect (Enterprise Edition)

Цей скіл налаштовує роботу Агента як універсального юридичного конструктора для потреб компанії або неприбуткової організації.

## ⚖️ 1. Сфера компетенції
Агент використовує цей скіл для підготовки:
- **Актів приймання-передачі** майна чи надання послуг.
- **Договорів** (підряд, волонтерська діяльність, партнерство, NDA)
- **Офіційних наказів** та внутрішніх розпоряджень.
- **Офіційних запитів/петицій** до органів державної влади.

## 🔧 2. Як викликати інструмент (CLI)

Коли користувач просить «згенеруй договір», «зроби акт» або «підготуй NDA» — агент ЗОБОВ'ЯЗАНИЙ викликати `legal_tool.py`, а не просто генерувати текст у чаті.

```bash
# Договір про надання послуг
python tools/legal_tool.py generate \
  --type contract \
  --party1 "ТОВ Назва Компанії" \
  --party2 "ФОП Прізвище" \
  --subject "Автоматизація бізнес-процесів" \
  --amount 50000 \
  --currency UAH

# Акт приймання-передачі
python tools/legal_tool.py generate \
  --type act \
  --party1 "ТОВ Назва" \
  --party2 "ФОП Партнер" \
  --subject "Виконані роботи за договором" \
  --amount 15000

# NDA
python tools/legal_tool.py generate --type nda --party1 "ТОВ Назва" --party2 "Партнер"

# Список документів
python tools/legal_tool.py list
```

Документи зберігаються у `.orchestrator/legal_docs/` у форматах `.md` та `.json`.

## 🔄 3. Протокол генерації документів
Перед запуском інструменту Агент ПОВИНЕН:
1. **Уточнити ціль:** (наприклад, «Акт передачі обладнання», «NDA з підрядником»).
2. **Запитати дані:** (Повні реквізити сторін, дати, предмет договору, сума).
3. **Запустити CLI:** Сформувати команду та виконати її.
4. **Повідомити:** Надати посилання на збережений файл.

## 📐 4. Технічні стандарти оформлення (ДСТУ)
- **Шрифт:** Times New Roman, 11-12 pt.
- **Поля:** Ліве — 30 мм, Праве — 10 мм, Верхнє/Нижнє — 20 мм.
- **Прізвища:** Підписанти завжди **ВЕЛИКИМИ ЛІТЕРАМИ** (напр. Іван ПЕТРЕНКО).
- **Підписи:** Сторона 1 — по ЛІВОМУ краю, Сторона 2 — по ПРАВОМУ краю.

## ⚠️ Застереження
Згенеровані документи є **чернетками (drafts)** і потребують перевірки юридичним відділом перед підписанням.
