# Universal Skill Architect (Універсальний Архітектор)

Цей скіл призначений для створення нових високоякісних розширень (скілів) для вашого агента. Він забезпечує єдиний стандарт архітектури, що дозволяє легко масштабувати можливості AI без втрати стабільності та ресурсів.

## 1. Архітектурні Патерни
При створенні нового скіла необхідно обрати один із базових патернів з [references/patterns.md](references/patterns.md):

| Патерн | Короткий опис | Основна перевага |
|--------|---------------|------------------|
| **Simple/Hub** | Диспетчер для 2-5 файлів | Швидкий доступ до різних тем |
| **Workflow** | Покрокове виконання процесу | Повний контроль над складними задачами |
| **Rules-Based** | Аудит за категоріями та правилами | Найвища точність та якість виходу |
| **Expert-System** | Глибокі спеціалізовані знання | Обробка складних контекстів |

## 2. Ключові Вимоги до Якості (CORE-4)

1. **Progressive Disclosure (PD)**: Основний файл `SKILL.md` має містити лише логіку вибору. Деталі виносяться у папку `references/`.
2. **Context Isolation**: Провідні інструкції не повинні перетинатися або суперечити іншим активним скілам.
3. **Token Stewardship**: Використання таблиць "Read When" для завантаження файлів лише тоді, коли виникає конкретний тригер.
4. **Validation Integrity**: Кожен скіл повинен мати вбудовані методи самоперевірки.

## 3. Процес Створення (Creation Pipeline)
1. **Scope Definition**: Визначення меж компетентності майбутнього скіла.
2. **Skeleton Creation**: Створення директорії `skills/<name>/` та базового `SKILL.md`.
3. **Reference Mapping**: Заповнення `references/` або `rules/` згідно з обраним патерном.
4. **Optimization**: Очищення від зайвих слів та дублювання знань, які AI вже має за замовчуванням.
5. **Verification**: Проходження чекліста з [references/verification.md](references/verification.md).

## 4. Гнучкість та Контекст
Хоча цей архітектор є універсальним, він підтримує "Контекстні Плагіни". При створенні скіла для конкретної організації (наприклад, ГО), специфічні правила безпеки та посилання на локальні бази знань додаються в окремий файл `references/context.md` всередині нового скіла.
