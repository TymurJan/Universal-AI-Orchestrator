# Talan Core Skill

Цей скіл налаштовує роботу Агента в рамках екосистеми ГО "Талан ЮА". **Правила цього скіла є універсальними та діють у всіх сесіях незалежно від профілю входу.**

> 🔴 **МОВА ВИВОДУ (АБСОЛЮТНИЙ ПРІОРИТЕТ):** Агент ЗОБОВ'ЯЗАНИЙ формувати плани виконання, артефакти, списки завдань та всі відповіді **виключно українською мовою**. Правило, чек-лист та few-shot приклади визначені в `artificial-soul-profile/SKILL.md` — вони є обов'язковими для виконання. Використання англійської мови у планах та відповідях є **КРИТИЧНОЮ ПОМИЛКОЮ**.

## 1. Специфіка Організації та Проєктів

- **Основна сутність:** ГО «Талан ЮА»
- **Ключовий проєкт:** Проєкт «Ашрам» (ПТСР-реабілітація).
- При роботі та спілкуванні з документацією Агент захищає інтереси організації та керується принципами безпеки.

## 2. Логотип та брендинг

- **Основний еталон:** `d:\ГО Талан UA\Установчі документи\image1.png` (верхній ряд, крайній правий) — для всіх офіційних документів.
- **Виняток:** `шрам-лого.png` — використовується лише для Google-форм та опитувальників безпосередньо в межах Проекту «Ашрам».
- Будь-яка заміна еталонного логотипу або шапки документа потребує прямого, явного погодження користувача.

## 3. Структура проєкту Talan UA Antigravity manager

Це еталонна структура для роботи:

```
Talan UA Antigravity manager/
├── .agent/skills/          — скіли агента

```

## 4. 🛡️ ОБОВ'ЯЗКОВИЙ ПРОТОКОЛ БЕЗПЕКИ ТА СТАБІЛЬНОСТІ

> ⚠️ **КРИТИЧНО.** Агент ЗОБОВ'ЯЗАНИЙ виконувати після кожної з подій:

### Тригери (коли запускати):

- Створено/змінено будь-який скіл у `.agents/skills/`
- Додано новий проєкт або папку
- Змінено структуру бота або автоматизації
- Перед завершенням сесії або переключенням проєкту

### Кроки протоколу:

**1️⃣ Оркестратор-аудит** — перевірити конфлікти між скілами, структуру, безпеку:

> Читай `.agents/skills/01-orchestrator/SKILL.md` та виконай аудит.

**2️⃣ Бекап** — завантажити архів на Google Drive:

```powershell
python talan/autobot/backup_manager.py
```

**3️⃣ Підтвердження** — повідомити: ✅ Аудит / ✅ Бекап / ❌ Помилка (деталі).

> **Без цього кроку робота сесії вважається незавершеною.**

Перед тим, як формувати відповідь користувачу, Агент **ЗОБОВ'ЯЗАНИЙ**:

1. Виконати список файлів у папці `📥_DROPZONE`.

3. **Технічний Контроль (Integrity Guard):** Після кожної зміни плану (`.md`) або коду (`.py`), Агент **ЗОБОВ'ЯЗАНИЙ** запустити перевірку:
   ```powershell
   python talan/autobot/integrity_guard.py <шлях_до_файла>

Агент зобов'язаний зберігати максимальну семантичну щільність директив користувача. Глобальне розуміння контексту зникає між сесіями, тому всі ключові інструкції мають залишатися дослівно деталізованими.
