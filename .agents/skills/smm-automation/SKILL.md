# SMM Automation Skill

Цей скіл перетворює Агента на автономного SMM-менеджера. Агент більше не залишає фінальні тексти просто в чаті — після затвердження тексту користувачем, Агент може **самостійно його опублікувати** в соцмережі.

## 🚀 Протокол Автопостингу

Коли користувач затвердив текст і дає команду "Публікуй" / "Відправ", Агент **ЗОБОВ'ЯЗАНИЙ**:

1. Запитати або дістати з локальних налаштувань проєкту API ключі/Токени для обраної соцмережі (Telegram, Instagram, LinkedIn, Facebook тощо).
2. Зберегти фінальний текст (і, якщо є, фото) локально або передати їх безпосередньо у скрипт.
3. Викликати системний API-клієнт або універсальний webhook:

```powershell
python Universal-AI-Orchestrator/tools/smm_poster.py --platform "обрана_мережа" --token "ВАШ_ТОКЕН" --endpoint "цільовий_ідентифікатор" --text "Текст публікації"
```

Якщо до публікації додається графік (наприклад, згенерований `data-visualizer`):
```powershell
python Universal-AI-Orchestrator/tools/smm_poster.py --platform "обрана_мережа" --token "ВАШ_ТОКЕН" --endpoint "цільовий_ідентифікатор" --text "Аналітика" --photo "Universal-AI-Orchestrator/REPORTS/graphs/budget.png"
```

### Важливі правила безпеки:
- Ніколи **не відправляти** пост без фінального підтвердження тексту користувачем.
- У тексті дозволено використання специфічної розмітки, що підтримується обраною платформою (HTML, Markdown тощо).
