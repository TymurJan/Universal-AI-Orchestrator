# 🔍 Web Scout v2.0 (Autonomous Monitoring) Setup

Цей документ містить інструкції щодо налаштування та використання універсального 3-шарового AI-Розвідника.

## 🌟 1. Архітектура та Можливості

Web Scout v2.0 — це універсальна система, яка може моніторити **БЕЗЛІЧ** різних напрямків одночасно (Гранти, Курси Валют, Закупівлі, Новини та ін.). Кожне джерело (URL) має свої налаштування цільового напрямку (`directions`) та бізнес-фільтрів (`filters`).

Конвеєр обробки складається з 3-х шарів:
- **Шар 1 (LLM-Розвідник):** Шукає нові URL за вашим запитом та автоматично додає їх до моніторингу.
- **Шар 2 (Keyword/Diff):** Економний сканер, який перевіряє тисячі URL на зміни (кожні 6/24 год).
- **Шар 3 (LLM-Аналітик):** При зміні тексту, читає нові рядки та приймає рішення (від 0.0 до 1.0) чи відповідають зміни вашим фільтрам. Новина публікується тільки якщо `score >= 0.5`.

## ⚙️ 2. Швидкий старт (Шаблони)

Ви можете заповнити список моніторингу миттєво, використавши шаблон:
```bash
# Перейдіть у папку Orchestrator
cd "d:\ГО Талан UA\Talan UA Antigravity manager\Universal-AI-Orchestrator"

# Використати шаблон
python tools/web_scout_tool.py template --use grants-ngo
```

## 🛠️ 3. Ручне керування

### Додати джерело
```bash
python tools/web_scout_tool.py watch \
  --url "https://bank.gov.ua" \
  --name "НБУ Курси" \
  --directions "Курси валют,Ставки" \
  --filters "відстежувати тільки зміни облікової ставки"
```

### Знайти нові джерела (Шар 1)
```bash
python tools/web_scout_tool.py discover \
  --query "Тендери для НДО Україна 2026" \
  --directions "НГО Тендери" \
  --filters "релевантні для соціальних послуг"
```

### Переглянути список
```bash
python tools/web_scout_tool.py list
```

## ⏰ 4. Автоматизація (Task Scheduler)

Для повної автономності, налаштуйте **Windows Task Scheduler**, щоб він щодня або кожні 6 годин викликав Шар 2/3.

1. Відкрийте PowerShell (від імені Адміністратора).
2. Запустіть створення щоденної задачі:
```powershell
schtasks /create /tn "WebScout_Scan_Daily" /tr "python 'd:\ГО Талан UA\Talan UA Antigravity manager\Universal-AI-Orchestrator\tools\web_scout_tool.py' scan --notify --token YOUR_TOKEN --chat YOUR_CHAT_ID" /sc DAILY /st 09:00
```
*(Не забудьте замінити YOUR_TOKEN та YOUR_CHAT_ID)*

## 📑 5. Звіти та Логування

Усі дії записуються у файл `logs/scout.log`. Якщо щось пішло не так — шукайте помилки там.
Усі детальні Markdown-звіти при знаходженні нових релевантних записів зберігаються у папці `logs/scout_reports/ALERT_***.md`.

## 🧪 6. Процедура Тестування (QA)

Щоб перевірити, чи все працює після оновлень:
1. Запустіть сканування `python tools/web_scout_tool.py scan` вручну.
2. Відкрийте файл `.orchestrator/scout_cache/snapshots/` і видаліть або змініть один з файлів (напр. додайте слово "Грант").
3. Запустіть `scan` знову і перевірте консоль: `🔔 АЛЕРТ! Знайдено релевантні зміни (Score: ...)`.
4. Знайдіть створений звіт `.md` у `logs/scout_reports/`.
