# 🔍 Web Scout v2.0 — Autonomous AI-Розвідник

Цей скіл дозволяє агенту налаштовувати **універсальний автоматичний моніторинг ресурсів** з використанням 3-шарової архітектури (Розвідник -> Сканер -> LLM-Аналітик). Скіл генерує подвійні звіти: у Telegram та Markdown.

## 🧠 3-Шаровий Конвеєр (Pipeline)

1. **Шар 1 (LLM-Розвідник):** За командою `discover`, використовує контекстний LLM-пошук в Інтернеті (через DuckDuckGo + GPT/Haiku) для знаходження НОВИХ сайтів і автоматичного додавання їх у `watchlist.json`.
2. **Шар 2 (Keyword/Hash Scan):** Базова швидка перевірка. Раз на 6/24 год (або за командою `scan`) перевіряє тисячі URL на будь-які зміни рядків коду сторінки. Безкоштовно та ефективно.
3. **Шар 3 (LLM-Аналітик):** Якщо знайдено зміни в Шарі 2, ці рядки надсилаються до LLM з вашими інструкціями (`directions`, `filters`). LLM надає їм бал релевантності (`relevance_score`). Лише якщо `score >= 0.5`, система надсилає Алерт.

## Як використовувати (CLI)

```bash
# 1. Заповнити розвідника шаблоном (Швидкий старт)
python tools/web_scout_tool.py template --use grants-ngo

# 2. Додати конкретне джерело вручну (Шар 2)
python tools/web_scout_tool.py watch \
  --url "https://bank.gov.ua" \
  --name "НБУ Курс" \
  --directions "Курси валют" \
  --filters "тільки зміни облікової ставки"

# 3. Знайти і додати НОВІ джерела за запитом (Шар 1)
python tools/web_scout_tool.py discover \
  --query "Тендери НДО Україна" \
  --directions "Тендери" \
  --filters "очікувана вартість більше 10к"

# 4. Сканувати та एनाлізувати всі джерела (Шари 2 і 3)
python tools/web_scout_tool.py scan --notify --token $TELEGRAM_TOKEN --chat $CHAT_ID
```

## Правила для Агента

1. **Ніколи не хардкодьте ключові слова.** По замовчуванню, для кожного об'єкта використовуйте `directions` та `filters`. Ця система має бути **універсальною**.
2. **Перевірка звітів:** Завжди радьте користувачеві перевірити папку `logs/scout_reports/`, щоб побачити розгорнуті Markdown-звіти про зміни.
3. Якщо користувач прямо не встановлює моніторинг, але цікавиться темою — обов'язково пропонуйте `discover`.

### 🧙‍♂️ Інтерактивний Майстер (Setup Wizard)
Якщо користувач в чаті пише слово **"моніторинг"** (або просить налаштувати моніторинг), ти **ПОВИНЕН** діяти як послідовний Майстер і НЕ намагатися заповнити аргументи навмання. 
Задавай строго по **ОДНОМУ** питанню за раз і чекай на відповідь:
1. **Крок 1 (Джерело):** Запитай "Що саме ви хочете моніторити? Дайте конкретні посилання (URL) або просто опишіть тему (я сам знайду джерела через розвідника)."
2. **Крок 2 (Напрямки):** Отримавши відповідь, запитай: "До якого напрямку чи категорії ми це віднесемо? (наприклад: Медичні Тендери, Ветеранські Гранти, Новини конкурентів)"
3. **Крок 3 (Фільтри):** Запитай: "Які у вас критерії відбору? (наприклад: сума більше 10к, дедлайн мінімум 2 тижні). Якщо фільтрів немає — будемо збирати все підряд."
*ТІЛЬКИ коли всі 3 кроки пройдені*, ти самостійно виконуєш команду `watch` або `discover` з отриманими параметрами і повідомляєш про успіх.
