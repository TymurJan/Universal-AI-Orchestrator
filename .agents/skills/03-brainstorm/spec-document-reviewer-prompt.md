# Spec Document Reviewer — Шаблон перевірки специфікації

Використовується після написання специфікації (дизайн-документа) перед переходом до реалізації.

## Що перевіряє

| Категорія | Що шукати |
|---|---|
| Повнота | TODO, TBD, незаповнені розділи |
| Покриття | Відсутня обробка помилок, крайні випадки |
| Узгодженість | Внутрішні суперечності |
| Ясність | Двозначні вимоги |
| YAGNI | Незапитані функції, надмірне проєктування |
| Обсяг | Один план — одна задача, не кілька незалежних систем |

## Формат результату

**Статус:** ✅ Схвалено | ❌ Є проблеми

**Проблеми (якщо є):**
- [Розділ X]: [конкретна проблема] — [чому важливо]

**Рекомендації (не блокують):**
- [Пропозиції що не заважають схваленню]
