# 🗺️ Реєстр Проектів ГО "Талан ЮА"

> **Правило:** Агент ЗОБОВ'ЯЗАНИЙ при кожному згадуванні проекту використовувати його **кодове ім'я** (колонка "Код"). Забороняється називати різні проекти однаковими словами.

| Код | Повна назва | Головний файл | Для кого | Тип |
|-----|-------------|---------------|----------|-----|
| **AG** | Antigravity Manager | `./bot.py` | Команда ГО (внутрішній) | Telegram-бот (telebot) |
| **NS** | Новий Шлях | `./Novy_Shlyakh_Portal/backend/bot.py` | Ветерани та спеціалісти | Telegram-бот (aiogram) |
| **UO** | Universal Orchestrator | `./Universal-AI-Orchestrator/` | B2B клієнти (комерційний) | Лендінг + Engine |

## Правила уникнення плутанини

1. **Ніколи** не кажи просто "бот" — завжди вказуй код: `AG-бот`, `NS-бот` або `UO-продукт`.
2. **Ніколи** не модифікуй файл одного проекту, думаючи, що це інший. Перед зміною — перевір шлях.
3. Якщо фіча логічно належить до **UO** (B2B), але тимчасово живе в **AG** — обов'язково залишай коментар `# TODO: migrate to UO`.
