# Роудмап проєкту «Ашрам» — ГО «ТАЛАН ЮА»

Цей документ визначає стратегічні цілі, поточні завдання та нюанси реалізації програми «Ашрам».

## 1. Поточний статус (Q1 2026)
*   **Основна мета:** Стабілізація поточної групи бенефіціарів та підготовка до масштабування.
*   **Ключовий пріоритет:** Юридична та цифрова безпека даних учасників.

| Квартал | Ціль | Очікуваний результат | Статус |
| :--- | :--- | :--- | :--- |
| **Q1 2026** | **"Цифровий Щит"** | Повне переведення бази бенефіціарів у зашифроване сховище (Zero Knowledge). | [/] |
| **Q2 2026** | **"Юридична Броня"** | Формалізація контрактів із консультантами та кризовими юристами. | [ ] |
| **Q3 2026** | **"Масштабування"** | Запуск другої хвилі програми для нових ветеранів / учасників. | [ ] |

## 3. Нюанси проєкту (Специфіка)
*   **Конфіденційність:** Дані учасників мають статус "Суворо конфіденційно". Доступ тільки через 2FA.
*   **Ризики:** Можливий тиск через специфіку роботи з ветеранами.
*   **Фінансування:** Грантова підтримка (деталі уточнюються).
