## 1. Теорія: HTTP та HTTPS — у чому різниця?

**HTTP (HyperText Transfer Protocol)** — базовий протокол для передачі веб-сторінок. Проблема полягає в тому, що всі дані передаються у **відкритому вигляді** (open text). Зловмисник, який перехопить трафік у публічній мережі (наприклад, Wi-Fi у кафе), зможе прочитати логіни, паролі та персональні дані ветеранів дослівно.

**HTTPS (HTTP Secure)** — це HTTP із шаром шифрування **TLS (Transport Layer Security)**. Навіть якщо зловмисник перехопить пакети даних, він побачить лише зашифрований набір байтів, непридатний для читання.

### Як працює TLS-рукостискання (Handshake):
1. Браузер запитує з'єднання з сервером.
2. Сервер надсилає свій **SSL-сертифікат** (цифровий документ, підписаний довіреним центром сертифікації — CA).
3. Браузер перевіряє підпис CA. Якщо все в порядку — замок у рядку браузера закривається.
4. Обидві сторони узгоджують тимчасовий симетричний ключ для шифрування сесії.
5. З цього моменту всі дані передаються зашифрованими алгоритмом **AES-256**.

---

## 2. Чому HTTPS критично важливий для нашого порталу?

На порталі «Новий Шлях» форма реєстрації ветерана містить **персональні та медичні дані**:
- Повне ім'я, дата народження.
- Контактний телефон та адреса.
- Статус та медичні потреби (ПТСР-реабілітація).

Без HTTPS ці дані можуть бути перехоплені при будь-якому вході в систему.

> **Правило GDPR (Стаття 32):** Організація зобов'язана застосовувати шифрування персональних даних як під час передачі (in transit), так і під час зберігання (at rest). Відсутність HTTPS — пряме порушення регламенту.

### Де взяти безкоштовний SSL-сертифікат?
**Let's Encrypt** — некомерційний центр сертифікації, який надає безкоштовні SSL-сертифікати. Інструмент **Certbot** автоматично встановлює та оновлює сертифікат на VPS кожні 90 днів.

## 3. Перевірка валідності SSL-сертифікату

Адміністратор порталу повинен регулярно перевіряти термін дії сертифіката, щоб сайт не опинився заблокованим з повідомленням "Ваше з'єднання не захищено".

## 4. Практичне домашнє завдання (ДЗ)

Ваше завдання — написати скрипт, який перевіряє SSL-сертифікат будь-якого сайту та виводить:
- Чи є сертифікат валідним.
- Кому виданий та хто його підписав (CA).
- Скільки днів залишилось до закінчення терміну дії.
- Попередження, якщо термін закінчується менш ніж за 14 днів.

### Файл для виконання: `Talan_Academy/practice/homework_2.py`

*Шаблон коду:*
```python
import ssl
import socket
from datetime import datetime

def check_ssl_certificate(hostname: str) -> None:
    context = ssl.create_default_context()
    with socket.create_connection((hostname, 443)) as sock:
        with context.wrap_socket(sock, server_hostname=hostname) as ssock:
            cert = ssock.getpeercert()
    
    # Дата закінчення дії сертифіката
    expires_str = cert["notAfter"]
    expires_date = datetime.strptime(expires_str, "%b %d %H:%M:%S %Y %Z")
    days_left = (expires_date - datetime.utcnow()).days
    
    print(f"Сайт: {hostname}")
    print(f"Виданий для: {cert['subject']}")
    print(f"Дійсний до: {expires_date.strftime('%d.%m.%Y')}")
    print(f"Днів залишилось: {days_left}")
    
    if days_left < 14:
        print("⚠️ ПОПЕРЕДЖЕННЯ: Сертифікат закінчується менш ніж за 14 днів!")
    else:
        print("✅ Сертифікат в нормі.")

check_ssl_certificate("google.com")
```
