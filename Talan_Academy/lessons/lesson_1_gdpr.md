## 1. Теорія: Що таке GDPR та як захистити дані?

**GDPR (General Data Protection Regulation)** — це суворий європейський регламент захисту персональних даних. Навіть якщо ми працюємо в Україні, дотримання його принципів — ознака професіоналізму та обов'язкова вимога міжнародних донорів (IREX, USAID тощо).

### Ключові принципи:
1. **Privacy by Design:** Безпека має проектуватися разом із архітектурою, а не додаватися "колись потім".
2. **Мінімізація даних:** Зберігайте лише те, що критично необхідно.
3. **Обмеження зберігання:** Дані мають видалятися або знеособлюватися після досягнення мети.

### Два типи шифрування:
* **Encryption in Transit (при передачі):** Захищає дані під час руху мережею від вашого сервера до користувача (HTTPS/SSL, TLS). Запобігає перехопленню (атакам Man-in-the-Middle).
* **Encryption at Rest (при зберіганні):** Захищає дані, коли вони лежать на диску в базі даних (наприклад, алгоритмом AES-256). Якщо зловмисник вкраде файл бази даних SQLite з VPS, без секретного ключа він побачить лише кашу з символів.

## 2. Як це стосується нашого проєкту?

На нашому порталі «Новий Шлях» зберігаються персональні дані ветеранів (ПІБ, контакти, статус, медичні потреби).
* **Ризик:** База даних порталу (SQLite/PostgreSQL) буде розгорнута на VPS. VPS — це публічна хмара. У разі компрометації хостингу дані можуть витекти.
* **Рішення:** Застосувати **Encryption at Rest** для найбільш чутливих полів (наприклад, контакти ветерана, деталі статусу). Сам пароль користувача ми хешуємо (через bcrypt/argon2), а от персональні дані маємо саме шифрувати (щоб система могла їх розшифрувати для показу адміністратору, але не зберігала відкритими).

## 3. Практичне домашнє завдання (ДЗ)

Ваше завдання — створити тестовий скрипт для шифрування та розшифрування текстових даних за допомогою симетричного алгоритму (Fernet / AES).

### Кроки для виконання в IDE:
1. Створіть файл у папці `Talan_Academy/practice/homework_1.py`.
2. Встановіть бібліотеку `cryptography`: `pip install cryptography`.
3. Напишіть скрипт, який:
   - Генерує ключ шифрування.
   - Шифрує рядок: `"Персональні дані ветерана: Іванченко Сергій, телефон +380991112233"`.
   - Виводить зашифрований рядок на екран.
   - Розшифровує його назад і виводить оригінал.

*Приклад шаблону коду:*
```python
from cryptography.fernet import Fernet

# 1. Генерація ключа
key = Fernet.generate_key()
cipher = Fernet(key)

# 2. Шифрування
secret_data = "Чутливі дані ветерана".encode()
encrypted = cipher.encrypt(secret_data)
print("Зашифровано:", encrypted)

# 3. Розшифрування
decrypted = cipher.decrypt(encrypted)
print("Розшифровано:", decrypted.decode())
```
