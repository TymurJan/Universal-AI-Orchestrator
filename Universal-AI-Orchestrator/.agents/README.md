# `.agents` — продуктові скіли (Universal AI Orchestrator)

Скіли в цій папці входять до **комерційного продукту** для зовнішнього покупця.

## Абсолютні заборони (DE-NGO / DE-CLIENT)

У `SKILL.md`, шаблонах, прикладах і CLI **заборонено**:

- назви конкретних ГО, брендів замовника, внутрішніх проєктів;
- шляхи типу `d:\ГО Талан UA\...`, `_DROPZONE` цього репо (замість них — `inputs/`, `Knowledge_Base/` у workspace **клієнта**);
- КВЕДи, логотипи, email-и та контакти з приватного репозиторію.

**Дозволено:** типи донорів (USAID, EU, UN), загальні платформи, універсальна методологія.

## Джерело правди для універсальної логіки

Покращення методології (grant pipeline, compliance, red flags) вносяться **сюди першими**, потім за потреби — у локальний `.agents/` репозиторію власника з `context_*.md`.

## Синхронізація grant-скілу

| Продукт (продаж) | Локальний агент (приватний) |
| :--------------- | :-------------------------- |
| `skills/grant-funding-specialist/` | `skills/03-grant-writer/` |
| `Grant_Core_Methodology.md` | `Talan_Grant_Methodology.md` + контекст ГО |

Версії скілу узгоджуються в `version` у frontmatter.
