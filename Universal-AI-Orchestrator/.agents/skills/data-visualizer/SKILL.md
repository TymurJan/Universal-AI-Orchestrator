# Data Visualizer Skill

Цей скіл наділяє Агента здатністю **малювати графіки**, перетворюючи сирі дані на професійні PNG-картинки за допомогою вбудованого у ядро скрипту `visualizer_tool.py`.

## 🎨 Можливості

Агент може згенерувати 3 типи графіків:
1. `pie` — кругова діаграма.
2. `bar` — стовпчаста діаграма.
3. `gantt` — таймлайн реалізації проєкту.

## ⚙️ Протокол виклику візуалізатора

Коли користувач просить намалювати графік (наприклад, "бюджет Внутрішній Проєкту", "діаграму ЦА", "графік продажів"), Агент **ЗОБОВ'ЯЗАНИЙ**:

1. Сформувати JSON-строку з даними у відповідному форматі.
2. Викликати системну команду для генерації графіка:

```powershell
python Universal-AI-Orchestrator/tools/visualizer_tool.py <ТИП> '<ДАНІ_JSON>' "<ЗАГОЛОВОК>" "<НАЗВА_ФАЙЛУ>"
```

### Приклади JSON-форматів:

**Для `pie` та `bar`:**
`'{"labels": ["Зарплати", "Обладнання", "Реклама"], "values": [50000, 30000, 20000]}'`

**Для `gantt`:**
`'[{"name": "Підготовка", "start": 0, "duration": 1}, {"name": "Ремонт", "start": 1, "duration": 3}]'`

### Приклад виконання Агентом:
Користувач просить круглу діаграму бюджету. Агент запускає:
```powershell
python Universal-AI-Orchestrator/tools/visualizer_tool.py pie '{"labels": ["Психологи", "Оренда", "Резерв"], "values": [40, 45, 15]}' "Розподіл бюджету" "budget_pie"
```

Після генерації Агент повідомляє користувачу, що графік збережено у папці `Universal-AI-Orchestrator/REPORTS/graphs/budget_pie.png`.
