# Smart ROI Optimizer & Token Router

Цей скіл наділяє Агента **фінансовою свідомістю**. Агент не відправляє масивні завдання автоматично до найдорожчих моделей (напр. GPT-4o або Claude 3.5 Sonnet), а залучає алгоритм Smart Routing для вибору найдешевшої моделі, яка здатна виконати завдання із заданою якістю.

## 🎯 Як це працює

Коли користувач ініціює велику чи ресурсоємну задачу (напр., розбір 50-сторінкового PDF-документа, масова категоризація даних), Агент:
1. Запитує утиліту `roi_optimizer.py`, передаючи приблизну кількість слів вхідного тексту та бажаного результату.
2. Вказує бажаний рівень якості:
   - `high` — глибокий логічний аналіз, кодування, створення стратегій.
   - `standard` — створення чернеток, витяг фактів, генерація звітів.
   - `fast` — дуже прості завдання, класифікація, переклади, структурування JSON.
3. Отримує від утиліти порівняльний звіт вартості по різних моделях.
4. Повідомляє користувачеві: "Задачу спрямовано до [Модель X]. Зекономлено [Y]% бюджету."

## Як використовувати (CLI)

```bash
# Оцінка задачі середньої складності (наприклад, написання статті)
python tools/roi_optimizer.py estimate --input_words 1500 --output_words 800 --quality "standard"

# Оцінка складної задачі (наприклад, аналіз коду чи складна архітектура)
python tools/roi_optimizer.py estimate --input_words 10000 --output_words 2000 --quality "high"

# Оцінка рутини (витяг адрес з великого тексту)
python tools/roi_optimizer.py estimate --input_words 50000 --output_words 500 --quality "fast"
```

## Правила для Агента

1. **Економія за замовчуванням:** Якщо користувач прямо не каже "використовуй найпотужнішу модель", Агент зобов'язаний спробувати залучити дешевшу модель (Haiku / GPT-4o-mini) для рутинних задач.
2. **Прозорість (Transparency):** Агент повинен повідомляти користувачу (в Логах або UI) про те, яку конкретно модель було обрано для поточної операції.
3. Цей інструмент підтверджує обіцянку продукту: **"ROI Optimizer до 40%"**.
