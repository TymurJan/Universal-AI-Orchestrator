# Grant Core Methodology (Universal)

Універсальний алгоритм підготовки грантових заявок для **будь-якого** заявника (НУО, соціальне підприємство, муніципалітет, стартап).

---

## 1. Недоторканність шаблону донора

- Не змінювати шрифти, інтервали, кольори, задані грантодавцем.
- Зберігати вбудовані інструкції в формі, якщо донор не вимагає їх видалити.
- У таблицях — лише **додавати рядки**; не перейменовувати стовпці.

## 2. Подвійна верифікація (Крок А + Крок Б)

- **Крок А:** примітки в аплікаційній формі (ліміти, підказки).
- **Крок Б:** RFA, guidelines, бюджетний шаблон, список annex.
- **Пріоритет:** Крок Б > Крок А.

**Артефакти:** `COMPLIANCE_MAP_*`, `RED_FLAG_*`. Без RFA/форми — **ТЗ**, не «готова заявка».

## 3. Психоемоційна мова (в межах SMART)

Емпатія — в анотації, проблемі, ЦА. Мета, завдання, бюджет — суворо прагматичні.

## 4. Ефект метелика

Анотація → ЦА → План → Ризики → Бюджет (явні та неявні витрати, ціни з джерелами).

## 5. Інформаційний супровід

Фази: анонс → процес → результат. Канали релевантні аудиторії та звітності донору.
