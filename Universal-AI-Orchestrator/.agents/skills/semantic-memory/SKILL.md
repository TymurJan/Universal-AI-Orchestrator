# Semantic Memory Skill (Векторна RAG Пам'ять)

Цей скіл наділяє Агента **автономною довгостроковою пам'яттю**. Усі нотатки Universal AI Orchestrator, які завантажені у `Knowledge_Base`, автоматично перетворені на векторний формат і зберігаються в локальній базі `.orchestrator/chroma_db/`.

## 🧠 Протокол звернення до пам'яті

Коли користувач ставить складне запитання щодо історії рішень, цифр з минулих грантів, аргументацій або деталей, які очевидно потребують занурення в старі записи, Агент **ЗОБОВ'ЯЗАНИЙ** використати свою пам'ять СЕРЕД ПЕРШИХ ДІЙ.

### Як шукати в пам'яті:
Замість того, щоб вгадувати або запускати `grep_search` по всій файловій системі, Агент викликає інструмент Vector RAG:

```powershell
python Universal-AI-Orchestrator/tools/memory_tool.py query "тут ваш пошуковий текстовий запит"
```
*Запит має бути описовим (наприклад: "статистика ПТСР серед ветеранів", "вимоги до бюджету МХП", "які активності плануються в Внутрішній Проєкті").*

### Як запам'ятовувати нове в реальному часі:
Якщо в процесі діалогу генерується важливий висновок, ідея або фінальний текст, який має залишитись у пам'яті організації НАЗАВЖДИ, Агент може явно завантажити його туди:

```powershell
python Universal-AI-Orchestrator/tools/memory_tool.py add "Текст ідеї" -s "Діалог з користувачем [ДАТА]"
```

## ⚠️ Обмеження та безпека
- **Локальність:** База є повністю локальною. Усі дані Universal AI Orchestrator залишаються на пристрої.
- **Точність:** Пам'ять не є абсолютною істиною. Якщо вона видає суперечливі результати, Агент має їх проаналізувати або попросити у користувача уточнення.
- **Синхронізація (Sync):** Якщо користувач додав багато нових файлів або ми провели масовий бекап, Агент може одноразово виконати команду `python tools/memory_tool.py sync "Knowledge_Base"` для масового оновлення бази.
