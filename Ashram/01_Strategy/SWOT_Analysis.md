# Ashram: SWOT-аналіз

| Сильні сторони (Strengths) | Слабкі сторони (Weaknesses) |
| :--- | :--- |
| - Наявність чіткої концепції (8 модулів курсу). | - Обмеженість початкового бюджету. |
| - Підтримка ГО «Талан ЮА». | - Потреба у залученні вузькопрофільних фахівців (психологи). |
| - Реальний попит у громаді (анкетні дані). | - Залежність від зовнішніх донорів. |

| Можливості (Opportunities) | Загрози (Threats) |
| :--- | :--- |
| - Грантова підтримка (УВФ, USAID, ПРООН). | - Зміни в законодавстві або воєнна обстановка. |
| - Вихід на міжнародних партнерів. | - «Повзучість області» (неконтрольоване зростання завдань). |
| - Масштабування досвіду на інші громади. | - Вигорання команди. |
