# 🛡️ Політика Безпеки та Приватності Даних

Universal AI Orchestrator розроблений з пріоритетом на «нульову довіру» та максимальну локалізацію даних.

## 1. Де зберігаються Ваші дані?
- **Промпти та відповіді**: Всі текстові дані обробляються в оперативній пам'яті та передаються безпосередньо в API провайдера (OpenAI/Anthropic) через зашифроване з'єднання TLS 1.3.
- **Локальні логи (Black Box)**: Зберігаються виключно на Вашому комп'ютері в папці `logs/`. Розробник (ГО «Талан ЮА») не має автоматичного доступу до цих файлів.

## 2. Чи навчаються моделі на Ваших даних?
- **КАТЕГОРИЧНО НІ**. Ми використовуємо корпоративні API-інтерфейси провайдерів. Згідно з умовами OpenAI Enterprise та Anthropic Commercial, дані, передані через API, **не використовуються для навчання базових моделей ШІ**.
- Ваша інтелектуальна власність та комерційна таємниця залишаються Вашими.

## 3. Захист від несанкціонованого доступу
- **HWID Binding**: Кожна ліцензія жорстко прив'язана до ідентифікатора Вашого «заліза». Це унеможливлює використання Вашого ключа та Ваших налаштувань сторонніми особами на інших пристроях.

## 4. Оновлення та Безпека
- Система автоматично перевіряє цілісність своїх модулів при кожному запуску.
- Будь-яка модифікація коду сторонніми програмами (вірусами чи скринграбберами) буде виявлена модулем Integrity Guard.
