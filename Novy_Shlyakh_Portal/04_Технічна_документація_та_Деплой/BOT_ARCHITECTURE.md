# 🤖 Архітектура Telegram-бота "Новий Шлях"

## 1. СТРУКТУРА МЕНЮ (/start)
При першому вході користувач обирає свою роль:
- **[🎖️ Я Ветеран / Родина]** -> Перехід до `Veteran_Flow`
- **[💼 Я Спеціаліст]** -> Перехід до `Specialist_Flow`
- **[🛡️ Адмін-панель]** -> (Тільки для авторизованих ID)

---

## 2. VETERAN FLOW (Шлях Ветерана)
**Головне меню:**
1. **🔍 Знайти фахівця** (Категорії: Юрист, Психолог, Реабілітація, Кар'єра)
   - Результат: Картки спеціалістів Черкас з кнопками [📞 Дзвонити] та [📍 Мапа]
2. **🤖 Питання до ШІ**
   - Прямий діалог з нашим AI Scout (RAG на базі статуту та законів)
3. **🌐 Відкрити Портал** (Telegram Web App)
   - Запуск порталу всередині Telegram

---

## 3. SPECIALIST FLOW (Реєстрація)
Використовується FSM (Машина станів) для збору даних:
1. **Крок 1:** "Введіть ваше ПІБ та посаду"
2. **Крок 2:** "Оберіть категорію" (Inline кнопки)
3. **Крок 3:** "Надішліть вашу адресу у Черкасах або локацію"
4. **Крок 4:** "Ваш номер телефону для зв'язку"
5. **Крок 5:** "Опишіть ваші пільгові умови для ветеранів"
6. **Фінал:** "Дякуємо! Ваша заявка на модерації. Ми повідомимо про активацію."

---

## 4. ADMIN FLOW (Модерація)
Коли спеціаліст завершує реєстрацію, Адмін (Тимур) отримує повідомлення:
> 🆕 **Новий фахівець:** [Ім'я]
> **Категорія:** [Тип]
> **Умови:** [Опис]
> 
> [✅ Схвалити] | [❌ Відхилити] | [💬 Чат з ним]

**При натисканні [✅ Схвалити]:**
- Бот автоматично вносить дані в `specialists.json`
- Спеціаліст отримує повідомлення про успіх.

---

## 5. ТЕХНІЧНИЙ СТЕК
- **Мова:** Python 3.10+
- **Бібліотека:** aiogram 3.x
- **База даних:** JSON (для MVP) + синхронізація з Порталом.
- **AI Engine:** OpenAI / Claude API з нашим системним промптом.
- **Hosting:** CloudRun або локальний сервер з доступом до проєкту.
