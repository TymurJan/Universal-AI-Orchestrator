# Регламент оформлення офіційних документів ГО «ТАЛАН ЮА»

Даний документ встановлює єдині стандарти підготовки організаційно-розпорядчої документації для забезпечення професійного обліку та юридичної відповідності (ДСТУ 4163:2020).

## 📐 1. Технічні параметри верстки

| Параметр | Значення | Примітка |
| :--- | :--- | :--- |
| **Шрифт** | **Times New Roman** | Офіційний стандарт |
| **Розмір шрифту** | **11 pt** | Для компактності та читабельності |
| **Поля** | **30 мм (Л), 10 мм (П), 20 мм (В/Н)** | ДСТУ 4163:2020 |
| **Обсяг** | **Гнучкий (Smart Layout)** | 1 сторінка або збалансовані 2+ |

## ⚖️ 2. Юридична уніфікація (Сторони)
- **ГО «ТАЛАН ЮА»** — надалі **«Сторона 1»**.
- **Контрагент/Партнер** — надалі **«Сторона 2»**.

## 🛡️ 3. Юридична безпека та Збалансована верстка

Цей розділ гарантує нерозривність та захист документа від підміни аркушів:

1. **Заборона порожніх аркушів**: Блок підписів **ніколи** не може знаходитися на окремому аркуші без тексту.
2. **Збалансований перенос (Keep-Together)**: У разі переносу на нову сторінку, мінімум один пункт тексту (абзац) має переноситися разом із підписами.
3. **М'яке розтягування (Soft Stretching)**: Якщо документ виходить за межі 1 сторінки, відступи між абзацами автоматично збільшуються (`Pt(8)-Pt(10)`), щоб рівномірно заповнити першу сторінку та усунути порожнечі внизу.
4. **Стиснення (Compact Mode)**: Якщо документ перевищує 1 сторінку лише на 5-10%, застосовується стиснення відступів (`Pt(1)-Pt(2)`) для його вміщення на один аркуш.

## 📝 4. Правила оформлення реквізитів
- **Прізвища**: Завжди **ВЕЛИКИМИ ЛІТЕРАМИ** (напр. Т.Ю. ШАПОВАЛ).
- **Підписи**: Сторона 1 — по лівому краю, Сторона 2 — по правому. Заголовок «Підписи сторін:» — центрований, не жирний.
- **ТГ**: Завжди з великої — **Територіальна Громада**.

---
*Примітка: Ці стандарти автоматично виконуються генератором документів ГО.*
