# 📋 Протокол первинного інтерв'ю (Intake Protocol) v1.0
## Координаційний центр реінтеграції ветеранів «Новий Шлях»

### 1. Мета протоколу
Швидке визначення критичних потреб ветерана (Тріаж), встановлення довірливого контакту та формування індивідуальної карти реінтеграції.

### 2. Структура інтерв'ю (Анкети)

#### **Блок А: Загальні дані (Реєстрація)**
*   ПІБ
*   Вік
*   Контакт (Телефон/Telegram)
*   Статус (УБД / Інвалідність / Учасник бойових дій / Ветеран)
*   Місце проживання (Черкаси / Область / Інше)

#### **Блок Б: Тріаж Потреб (Пріоритезація)**
*Запитання з оцінкою від 1 до 5 (де 5 — "потрібно негайно"):*
1. **Юридична підтримка:** (Статус, виплати, земля, житло).
2. **Психологічна допомога:** (Адаптація, сон, ПТСР, сімейні питання).
3. **Фізична реабілітація:** (Протезування, лікування, відновлення).
4. **Професійна реалізація:** (Навчання, зміна фаху, пошук роботи).

#### **Блок В: Стан Документів**
*   Наявність посвідчення УБД.
*   Статус виплат (отримує / затримка / відмова).
*   Відкриті юридичні справи (якщо є).

#### **Блок Г: Сім'я та Соціальне оточення**
*   Склад сім'ї.
*   Потреби дружини/дітей у підтримці.
*   Участь у ветеранських спільнотах.

### 3. Алгоритм дій після інтерв'ю
1.  **Видача «Карти Шляху»:** Список першочергових дій.
2.  **Доступ до Бази Спеціалістів:** Надання Персонального Коду для порталу/лендінгу.
3.  **Перший запис:** Менеджер допомагає записатися до спеціаліста з найвищим рейтингом.
4.  **Фоллоу-ап:** Дзвінок/повідомлення через 3 дні для перевірки результату першої консультації.
