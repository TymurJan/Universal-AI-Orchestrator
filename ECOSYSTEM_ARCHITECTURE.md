# 🌍 Генеральна Архітектура Екосистеми (Talan UA / Ashram / Novy Shlyakh)

*Цей документ є "Живим Паспортом" системи. Він оновлюється Агентом автоматично після кожної значної інновації або зміни логіки проекту.*

## 📌 1. Концепція Екосистеми та Стратегічні Вектори
Проєкт є багатовекторним **Universal AI Orchestrator** та платформою організаційного управління ГО «Талан ЮА». 

### Основні напрямки діяльності:
1. **Координаційний центр «Новий шлях» (ПРІОРИТЕТ):** Створення потужного центру реінтеграції ветеранів. Це командний проект, що об'єднує спеціалістів для системної підтримки захисників.
2. **Проєкт «Ашрам» (Ashram):** Спеціалізований проект ПТСР-реабілітації ветеранів. Зосереджений на створенні простору для відновлення та адаптації.
3. **ІТ-продукція (Universal AI Orchestrator):** Розробка та впровадження масштабованого SAAS-продукту. Сюди відноситься юридична автоматизація, цифрова безпека та соціально-грантова діяльність як інструменти розвитку продукту та ГО.
4. **Волонтерська діяльність:** Неперервний напрямок допомоги, що триває з 25 лютого 2022 року (звітність, збори коштів, оперативна допомога).

## 📂 2. Технічна Структура проектування (Код та Папки)
- **`bot.py`**: Головний Telegram-бот (Antigravity Manager V5). Multi-Model AI Orchestrator (GPT-4o-mini + Claude 3.5 Sonnet).
- **`talan/autobot/`**: Модулі автоматизації (backup, docx_generator, meta_optimizer).
- **`.agents/skills/`**: Навички агента (Legal, Grant Writer).
- **`.agents/workflows/`**: Регламенти (talanregulations.md).
- **`Knowledge_Base/`**: Структурована база знань по всіх 4-х напрямках.

## 🧠 3. Розумні Модулі (Agents Skills)
- **`01-orchestrator`**: Governance Guard та самодокументація.
- **`03-legal`**: Юридична стандартизація (ДСТУ) для «Нового шляху» та ІТ-продукту.
- **`03-grant-writer`**: Робота з донорами для соціальних проектів (Ashram, Новий шлях).
