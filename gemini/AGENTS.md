**АРХІТЕКТУРА ТА ТЕХНІЧНІ СТАНДАРТИ УПРАВЛІННЯ ШІ-АГЕНТАМИ**

**На основі принципів трирівневої архітектури та системи Eval-Driven Memory (EDM), нижче наведено перелік правил і стандартів для управління агентами.**

**СТАНДАРТИ УПРАВЛІННЯ ПАМ'ЯТТЮ ТА КОНСОЛІДАЦІЇ (EDM)**

* **Вибірковість: Довгострокова пам'ять функціонує як репозиторій досвіду, який варто повторювати, а не просто пасивне сховище**.
* **Поріг консолідації: Траєкторії вносяться до пам'яті лише за умови PEI (Planning Efficiency Index) >= 0.8 та TI (Traceability Index) >= 4.0**.
* **Пріоритет виклику: Перевага надається процедурній придатності (відповідності плану), а не лише семантичній схожості контенту**.
* **Ефективність: Завдяки фільтрації EDM досягає точності пам'яті MP=88% та знижує когнітивне навантаження на 25%**.

**ПРАВИЛА БЕЗПЕКИ ТА ДОСТУПУ**

* **Same-User Restriction: Програмна заборона доступу до даних інших користувачів; порушення повертає помилку 403 Forbidden**.
* **Детерміновані обмеження (Guardrails): Трьохрівнева фільтрація — перевірка входу на ін'єкції, обмеження інструментів під час обробки та перевірка виходу на галюцинації (grounding)**.
* **Шифрування: Усі дані шифруються за стандартами TLS 1.2+ для транзиту та AES-256 для зберігання**.

**ТЕХНІЧНІ ВИМОГИ ДО ВИКОНАННЯ**

* **Затримка: Цільовий час реакції системи на запит — менше 2 секунд**.
* **Ідемпотентність: Python-скрипти виконання мають бути ідемпотентними, щоб уникнути дублікатів або помилок при повторному запуску**.
* **Валідація: Перевірка вхідних даних на XSS-вразливості та фільтрація через список bad_words.json**.

**СТРУКТУРА МІРКУВАНЬ ТА ПРОМПТИНГУ**

* **Chain-of-Thought (CoT): Використання ланцюжків міркувань для логічних та математичних завдань**.
* **Рольова модель: Чітке закріплення ідентичності (наприклад, Senior Developer) для стабільності відповідей**.
* **Структурований вивід: Вимога формату JSON для забезпечення детермінованої обробки результатів кодом**.

**ЦИКЛ САМОВДОСКОНАЛЕННЯ (SELF-ANNEALING)**

* **Обробка помилок: При збої необхідно виправити код скрипта та оновити відповідний .md файл у папці directives/**.
* **Аудит: Фіксація всіх спроб авторизації та генерації документів у незмінному (immutable) журналі**.**-Cumulative Reliability: Надійність накопичується через постійне оновлення бази знань тільки перевіреним досвідом**.
